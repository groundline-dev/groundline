# API keys are hashed with SHA-256

groundline stores only a hash of each API key, never the key itself, and the hash is a plain SHA-256 rather than a password hash such as argon2 or bcrypt. Password hashes are slow and salted to protect secrets people choose, which are short and guessable. API keys are generated by groundline with at least 256 bits of randomness, so they can't be guessed however fast the hash is. A plain hash also lets the API find a key's row by looking up the hash of the key it was given, which a salted hash can't do without a separate key ID inside the key. This holds only while keys are generated, never chosen: if people could ever set their own keys, they would need a password hash.
