# HTTPS-only AWS deployments with restricted application access by default

Tester-only HTTP would still transmit API keys without encryption. Disposable AWS deployments therefore require HTTPS, default to `restricted` application access from the developer's public IP, and offer explicit `unrestricted` access; protected API endpoints require API keys in both modes. For the public-IP endpoints chosen in [ADR 0014](0014-public-ip-https-endpoints.md), certificate validation requires publicly reachable TCP 443. Caddy therefore filters application requests by their actual source IP and leaves TCP and TLS open, which keeps automatic certificate issuance and renewal working without a plaintext option.
