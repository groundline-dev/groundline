# HTTPS-only AWS deployments with restricted application access by default

Tester-only HTTP would still transmit API keys without encryption. Disposable AWS deployments therefore require HTTPS, default to `restricted` application access from the developer's public IP, and offer explicit `unrestricted` access; protected API endpoints require API keys in both modes. For the public-IP endpoints chosen in [ADR 0014](0014-public-ip-https-endpoints.md), certificate validation requires publicly reachable TCP 443, so Caddy filters application requests by their actual source IP while leaving TCP/TLS connectivity public, accepting broader TLS reachability to preserve automatic certificate issuance and renewal without retaining a plaintext deployment option.
