# Security

Please report a vulnerability privately, not in a public issue:

- through GitHub's [private vulnerability reporting](https://github.com/groundline-dev/groundline/security/advisories/new) for this repository, or
- by email to groundlinedevs@gmail.com.

Say which package and version you used (`groundline-core` or `groundline-client`), what you found, and how to reproduce it. Leave out real API keys and real patient data: an example with made-up values is enough.

groundline is pre-1.0 research code, and only the latest release gets fixes. We'll reply as soon as we can, but we can't promise a response time.
